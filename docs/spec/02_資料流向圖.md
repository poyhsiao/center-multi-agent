## 1. 核心資料流程概述

本系統有四大核心資料流程：
1. **身份驗證與授權流程** — Login → Token 核發 → 驗證
2. **Agent 操作流程** — 使用者操作 → Client 處理 → Server 驗證 → LLM 推理 → 執行
3. **知識貢獻流程** — 用戶提交 → 審核 → 發布
4. **Client 同步流程** — MCP/Skills 同步 → 設定檔同步

## 7. 資料生命週期

### 7.1 Token 生命週期

```
Lifetime: 14 days (configurable)

T=0:        Token issued + stored in Redis (for revocation check)
            + Device fingerprint bound

T=0~14d:    Every operation validates via Auth Service
            (Redis blacklist check for revocation)

T=14d:      Access Token expires

            Client → Auth Service: Refresh Token + Device FP
            Auth Service → Redis: Check not revoked
            Auth Service: Issue new Access Token + new Refresh Token

            Old Refresh Token: Mark as used (prevent replay)

T > 14d:    If Refresh Token also expired or revoked:
            Client must re-login (full authentication)
```

### 7.2 知識庫版本生命週期

```
User submits knowledge
    │
    ▼
[PENDING] ──▶ Org Admin reviews
    │              │
    │         [APPROVED]     [REJECTED]
    │              │              │
    ▼              ▼              ▼
[PUBLIC]     [PUBLIC]      [ARCHIVED with reason]
    │
    │ Changes proposed
    ▼
[PUBLIC] ──▶ New [PENDING] version
    │              │
    │         [APPROVED]
    │              │
    ▼              ▼
    (Old version retained for history)
```

### 7.3 佇列操作生命週期

```
Enqueued
    │
    │ Reconnect detected + User Manual Trigger
    ▼
[ATTEMPT_1]
    │ Success
    ▼
[COMPLETED]
    │
    │ Failure (network/server error)
    ▼
[RETRY_1] (after backoff)
    │ Success
    ▼
[COMPLETED]
    │
    │ Failure
    ▼
[RETRY_2]
    │ ...
    ▼
[RETRY_3]
    │ Failure
    ▼
[MANUAL_ACTION_REQUIRED]
    │ User resolves manually
    ▼
[RESOLVED]
```

## 8. SSE 通知事件類型

| 事件類型 | 觸發時機 | 接收者 |
|----------|----------|--------|
| `knowledge.pending_review` | 新知識待審核 | Org Admin |
| `knowledge.approved` | 知識審核通過 | 提交者 |
| `knowledge.rejected` | 知識審核拒絕 | 提交者 |
| `operation.manual_action_required` | 佇列操作需手動處理 | 操作者 |
| `quota.warning` | 用量接近上限（80%） | Org Admin + User |
| `quota.exceeded` | 用量超限 | Org Admin + User |
| `emergency_access` | Super Admin Emergency Access | Org Admin |
| `token.revoked` | Token 被撤銷 | Client Agent |
